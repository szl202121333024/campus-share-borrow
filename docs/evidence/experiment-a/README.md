## 3. 产出

`control-sample-app.py.txt`（单文件，372 行，Flask + SQLite + 服务端渲染，含内联模板）。

> **为什么扩展名是 `.py.txt`**：本仓库有守卫测试 `test_pc2_sqlite_connect_only_in_db` / `test_sqlite_connect_only_in_get_db`，扫描全树断言 `sqlite3.connect(` 只出现在 `db.py`。对照组代码自带 `sqlite3.connect(DB_PATH)`，以 `.py` 入库会直接把这两条守卫打红（实测：2 failed / 200 passed）。证据不是源码，故用 `.txt` 后缀让它退出扫描范围 —— 守卫本身工作正常，这条记录即为它有效的旁证。

对照组**自行假定**了技术栈，其原话：

> 「我无法看到项目技术栈，只能按假定的技术栈给出一个可直接运行的单文件实现：Flask + SQLite + 服务端渲染……如果实际项目是 Vue/React + Spring Boot/Node，或微信小程序，请把技术栈告诉我。」

它猜中了本项目的技术栈（Flask + SQLite + 服务端渲染）。这是本实验的重要前提：**所有"猜错"都建立在"它必须猜"之上**。
