# 作业需求摘要（阶段交接用）

> 本文件是「输入」，不是产物。作用：每次开新对话时，先读这份就能接上上下文。
> 课程作业的原始提示词见 `提示词.docx`（不在仓库内）。

## 1. 作业性质

研究生课程「AI 敏捷交付作业」，用 BMAD-Method v6 完整跑一遍 SDLC。
**评分核心不是代码质量，而是过程留痕与决策可追溯**：

- 代码能跑只是底线；
- 高分关键在于 `decision-log.md` 中有 **≥5 次成功否决或实质修改 AI 输出**的高质量决策；
- 必须完成一次**真实的对照实验**（实验 A），结论要诚实，不得给对照组放水。

## 2. 锁定基线（不允许发散）

| 项 | 内容 |
|---|---|
| 项目名称 | 校园共享器材 / 图书借阅系统 |
| 核心业务 | 登录、浏览、借阅、归还、管理员增删 |
| 核心并发风险 | 两人同时借阅同一件物品，必须只有一人成功，另一人收到冲突提示 |
| 技术栈 | SQLite 单文件库 + 服务端渲染（Flask + Jinja2 或 Node + EJS），**严禁前后端分离（React/Vue）** |

## 3. 作业硬性约束

1. **工作流隔离**：一个工作流 = 一个新对话；严禁同一对话里既写 PRD 又写代码；每次切换前明确提示「请开新对话」。
2. **不做实验 B**（变更注入已取消）。
3. **目录结构**：`_bmad-output/planning-artifacts/` 与 `_bmad-output/implementation-artifacts/`。
4. **根目录必须有**：`decision-log.md`、`retrospective.md`。

## 4. 产物底线（逐条可核验）

| 产物 | 数量 / 要求 |
|---|---|
| 史诗 | 3 个 |
| 用户故事 | ≥12 个（建议结构：认证与浏览 3 + 借阅与归还 5 + 管理员后台 4） |
| NFR | ≥2 条 |
| ADR | ≥5 条，**每条必须写明「否决的备选方案」** |
| `project-context.md` | ≥8 条实现规则 |
| `decision-log.md` | ≥15 条，其中 ≥5 条为人类实质否决/修改 |
| 实验 A | 1 次，对照实验，结论诚实 |

## 5. 需求范围（PRD 阶段需要覆盖）

**功能需求**：FR-1 登录 · FR-2 搜索 · FR-3 借阅 · FR-4 归还 · FR-5 限额 · FR-6 管理员。

**非功能需求**：
- NFR-1 并发一致性：两人同时借阅，只有一个成功（**全项目唯一技术难点**）。
- NFR-2 可运维：单文件库，一条命令启动。

**明确不做**：评论、图片上传、跨班共享。

## 6. 五个阶段

| 阶段 | 技能 | 要点 |
|---|---|---|
| 0 | `npx bmad-method install` + `bmad-help` | 已完成（v6.12.4） |
| 1 | `bmad-prd` | FR-1~FR-6、NFR-1/2、明确不做 |

## 7. 阶段 2 的两次「诱导否决」（作业设计的剧本）

1. **React 方案**：AI 先建议 React + RESTful，「为了现代感」→ 人类以 NFR-2（自己不懂运维）和工期为由否决，要求改为 Flask 服务端直接渲染 → **ADR-001**。
2. **先查后写**：AI 先建议 `SELECT` 查库存再 `UPDATE` 写入 → 人类指出这是并发漏洞，命令改用**唯一索引（Unique Index）**兜底并在代码中捕获异常 → **ADR-002**。

## 8. 四个强制决策点（AI 须主动暂停并给草稿）

1. 人类否决 React 方案。
2. 人类否决「先查后写」，要求唯一索引。
3. AI 发现人类要求的故事超出 PRD 范围。
4. AI 在测试中发现并发漏洞并修正。

草稿格式：触发 / 智能体建议 / 人类判断依据（指向 FR·NFR·ADR）/ 结果 / 事后验证。

## 9. 实验 A 设计

| 维度 | 实验组（走 BMAD） | 对照组（裸写） |
|---|---|---|
| 故事 | 2.2 归还功能 | 3.1 管理员添加物品 |
| 提供的上下文 | 需求 + 架构 + 项目规约 | 仅一句「帮我写一个添加物品的功能」 |
| 控制变量 | 同一人、同一天、同一模型 | 同 |
| 评审标准 | 完全相同 | 相同 |

**预期结论**（须如实验证，不得预设）：极简功能上完整规划增加阅读成本、收益为负；核心并发逻辑上架构前置避免返工。

## 10. 提交与留痕

- 每个阶段确认后立刻 `git commit`（如 `docs: add PRD`），目标 20+ 笔小而清晰的提交。
- AI 说出「发现决策点，建议记入 decision-log」时，人类截对话面板图。
- `README.md` 需含「AI 使用声明」。
